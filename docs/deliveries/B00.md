## 样例与限制

- 固定 ID 样例：`document_id("00000000-0000-4000-8000-000000000001", "src/example.py", "a" * 64, "fixture-parser-v1")` 得到 `1fd1f6cd-e83d-5ad1-818e-a40f63bca628`。
- 云 Chat 与云 Embedding 使用不同 profile/环境变量；默认离线且外部调用关闭。Qwen embedding 只允许 loopback。Rerank 的请求字段、响应字段和分数方向由 profile 指定。
- FakeProvider 与哈希向量仅提供离线确定性，不作为检索或生成质量证据。当前 provider 保存 token usage，但没有价格表；若货币预算需要单次成本估算而未提供，预算账本会拒绝该请求。
- 本节点不提供正式解析、抽取、存储、索引、Agent、PG/Qdrant service 或真实 provider 质量验收。P3 真实链路证据保留在 P3 记录中，本轮没有重新执行。
