## 接口样例

Python 结果含 `DEFINES` / `CONTAINS` / `IMPORTS` / `INHERITS` / 可静态解析的 `CALLS`。未知动态调用不创建关系，例如 `getattr(receiver, "run")()` 留下 `DYNAMIC_CALL_TARGET_UNRESOLVED`。

文本请求的核心输出形状：

```json
{
  "entities": [
    {"local_id": "e-alpha", "name": "Alpha", "kind": "concept", "mentions": [{"surface_form": "Alpha", "quote": "Alpha supports Beta."}], "aliases": []},
    {"local_id": "e-beta", "name": "Beta", "kind": "concept", "mentions": [{"surface_form": "Beta", "quote": "Alpha supports Beta."}], "aliases": []}
  ],
  "relations": [
    {"subject_local_id": "e-alpha", "predicate": "USES", "object_local_id": "e-beta", "polarity": "positive", "qualifiers": {"scope": "document", "confidence": 0.8}, "confidence": 0.8, "evidence": [{"surface_form": "Alpha supports Beta", "quote": "Alpha supports Beta."}]}
  ]
}
```

内部 response schema 将 `confidence` 与 semantic `qualifiers` 分开；结果 DTO 不含 confidence 字段，因此把它规范存入 relation `qualifiers["confidence"]`。quote 找不到、非唯一或不在 source-backed span 时拒绝关系并记录原因。

对齐样例：同名文本实体因 namespace 不同保持不同 ID；无映射证据的 `propose_text_alignment` 返回 `accepted=false`。quote 明确写出 “Gamma is also known as Gamma-X” 时返回 `ALIAS_EVIDENCE`；人工提供 mapping ID 时返回 `MANUAL`。该 helper 返回决策，不直接合并/改写 ID。
