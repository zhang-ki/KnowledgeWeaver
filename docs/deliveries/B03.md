## Interfaces and downstream use

`PipelineService.ingest(IngestRequest) -> IndexReport` and `delete_source(DeleteSourceRequest) -> IndexReport` publish a validated generation. `PostgresKnowledgeStore.resolve_context(corpus_id, request_id)` creates a lease; `get_chunk_evidence(chunk_ids, context)` resolves persisted evidence references. `Bm25Index`, `QdrantDenseIndex`, `SymbolIndex` and `EntityIndex` implement candidate search, while `PostgresGraphStore.snapshot(context)` returns a source-filtered closed graph snapshot. B04 can consume candidate hits and persistent chunk evidence; B05 can consume entity candidates and graph snapshots without importing B04.

The dense test path uses `FakeEmbeddingProvider(16)`. No live embedding provider was invoked. Cross-store publication is compensated but is not a distributed transaction. Parser caching remains process-local, and generation GC does not physically delete canonical facts.
