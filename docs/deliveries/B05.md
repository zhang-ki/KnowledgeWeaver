## 接口样例与后继消费

```python
result = await graph_retriever.retrieve(
    RetrievalQuery(text="Pipeline evidence", context=context, top_k=10,
                   entity_ids=[pipeline_entity_id])
)
for path in result.paths:
    for step in path.steps:
        # step.relation_id 关联 GraphSnapshot 原始关系；step.evidence_ids 对应本跳原文
        ...
for hit in result.hits:
    # 用 KnowledgeStore.get_evidence/get_chunks 取 quote、locator 和原始 chunk 文本
    print(hit.chunk_id, hit.evidence_ids, hit.score, hit.path_ids)
```

默认 GraphOptions 为 2 跳/200 边，合同硬上限为 3 跳/500 边；score 为 `1/(1+hops)`，同 chunk 汇总取最高分。完整路径的各跳 evidence chunk 都随结果返回。下游可直接将实例装配到 B06/B08；source filter 与 generation 必须沿用同一个 QueryContext。显式 `include_inferred=true` 才会允许符合证据校验的推断边进入候选。
