## 模块与契约

正式实现位于 `knowledge_weaver.ingestion`。`StructuralParser` 实现冻结的异步 `Parser` port，`StructuralChunker` 实现同步 `Chunker` port。公共 models/ports 未修改。由于冻结 DTO 没有文件级增删改报告字段，`ManifestBuilder` 提供本地 `ManifestResult` 和 `SourceChanges`，不扩展公共 schema。

- `paths.py`：规范化私有根和相对路径，拒绝绝对路径、盘符/ADS、空/点/父目录分量、符号链接及 Windows reparse point；提供有界 DOCX ZIP 校验和流式 SHA-256。
- `fingerprints.py`：将实现版本、源类型、解析依赖版本和影响解析的配置纳入指纹。PDF 默认禁用 OCR、远程服务、外部插件和页面图像；可用 `KW_DOCLING_MODEL_FINGERPRINT` 固定本地模型身份。
- `manifest.py`：枚举四种支持类型，应用文件数/字节上限，生成稳定 `FileManifestEntry`、`SourceVersion`，对比前一版本并报告 added/changed/unchanged/deleted。未显式给出 revision/dirty 时只读本地 Git 元数据；不执行仓库文件。
- `parser.py`：按清单重验路径、大小、原始 hash 和 parser 指纹后解析。Python 源码仅用 `ast.parse` 静态解析，不导入/执行；Markdown 使用 CommonMark token；DOCX 保留正文段落/表格顺序；PDF 使用离线 Docling 配置并保留页码、bbox、标题路径和表格单元。PDF 表格结构模型失败时关闭该步骤重试并给出 warning。已知 I/O、解析值/结构、运行时和 DTO 校验错误转成安全拒绝结果；未知程序异常继续抛出，避免伪装成普通坏文件。实例内 LRU 只复用同一稳定文档 ID。
- `tables.py`：按行列确定性渲染单元格；单元格文本有 source span，合成 tab/newline 分隔符没有证据 span。
- `chunker.py`：产生结构父块和叶块；Python 符号依据 qualname 建立父子关系，超大 Python 块尝试按 AST 语句拆分，超大表格按行/单元格拆分，其他文本按边界拆分。超过叶块上限明确抛出 `ChunkLimitExceeded`，不静默截断。`split_many` 对重复叶文本设置 group ID，仍保留每个源文档和 span。

调用顺序示例：`ManifestBuilder().build(source, allowed_root, previous=prior, revision=..., dirty=...)`；把返回的 `source_version` 放入冻结的 `ParseRequest` 后调用 `await StructuralParser().parse(request)`；将每个 `Document` 交给 `StructuralChunker().split(document, chunk_config)`。`parse_detailed` 可同时返回进程内复用的文档 ID，manifest 变化报告由调用方保留/消费。

## 边界与限制

- DOCX ZIP 默认限制 10,000 个成员、64 MiB 解压总量、单项压缩比 1,000；`ParseLimits` 再限制源文件数量和字节数。越界、坏归档、路径逃逸、哈希变化和不匹配的文档 ID 均作为拒绝结果报告。
- parser cache 是进程内缓存，不提供持久化缓存。manifest 变更列表包含删除项，解析结果只包含当前有效文件。
- Markdown/Python 块定位到原文区间；PDF/DOCX 由结构块组合成带 `\n\n` 的标准化文档文本，组合分隔符不覆盖任何 Block/Chunk span。
- PDF 当前未在本轮运行真实 Docling/模型。映射与 bbox 由隔离的合成对象验证；B01 的 P1 记录称 TableFormer 模型结构化验证未完成。未配置模型指纹时输出 `PDF_MODEL_FINGERPRINT_UNPINNED` warning。
- 迁移前 Anaconda 替代环境缺少锁定 Python 3.11/uv 项目环境、`python-docx`、Ruff 与 `pytest-asyncio`；其中 DOCX 测试后续已在共享 Python 环境门禁中执行通过。综合回归中的 9 个 B00 async 测试因替代环境缺少 pytest 插件而跳过，不作为共享环境证据。Windows 不允许本轮建立符号链接，链接逃逸测试仍为 skip。测试中的异步 wrapper 使用即时 `to_thread` 替身，以绕过替代 Anaconda 环境的 Windows Proactor loop 初始化挂起；未验证线程池调度。
