# B02 实现说明

## 边界与入口

`KnowledgeExtractor` 实现冻结的 `Extractor.extract(ExtractionRequest)`。`.py` / `.pyi` 文件进入只读 AST 分析；其他文件按 leaf chunk 调用注入的 `GenerationProvider` 做结构化抽取。没有文本 provider 时返回带拒绝原因的空结果，不伪造成功关系。

冻结的 `ExtractionRequest` 没有 `corpus_id`，实体 ID 却必须按 corpus 作用域派生。实现因此要求在构造 `KnowledgeExtractor` 时传单一 `corpus_id`，或提供 `source_id -> corpus_id` 映射；缺少映射时 fail closed。该选择不更改公共 DTO。

输入 `Document` / `Chunk` 均不被修改。仅处理属于该 document 的 leaf chunk；父块只作为上下文，不成为证据来源。错误 document 的 chunk 写入 `rejected_items` 并排除。

## 静态 Python

- 仅使用 `ast.parse`，不导入或执行待分析代码。
- `DEFINES` 与 `CONTAINS` 使用符号声明头证据；`IMPORTS` 使用 import 语句证据；`INHERITS` 只接受静态 Name / Attribute base；`CALLS` 只接受本文件声明、已记录 import、当前 class 直接声明的方法等可静态解析目标。
- AST UTF-8 byte column 转为 Unicode codepoint 偏移，再映射到 leaf chunk 的 source-backed span 和 Python locator。没有完整 source span 时拒绝该项。
- 无法解析的动态调用、星号导入和动态继承写入带行号的拒绝记录；不生成占位事实。继承链遍历、外部模块解析和完整 call graph 不在范围内。

## 文本实体、关系与证据

- 每个 leaf chunk 单独请求 JSON 结构：实体候选、候选 ID、提及/别名的 surface form 与 quote，以及关系端点、谓词、polarity、qualifiers、可选 confidence 和 evidence quotes。未提供 confidence 时按 `None` 处理。
- Provider 输出先按本地 JSON Schema 校验，再由 Pydantic 校验。最多允许一次 schema repair；超时、provider 错误、非法响应、缺字段、伪 quote 与无效端点均保留拒绝原因。
- quote 必须未填充、精确匹配当前 chunk 的 source-backed span，并在该 chunk 中唯一定位。重叠 chunk 指向同一 document offset 时按同一位置处理；多个原文位置时拒绝。
- 文本实体 namespace 为 `text:<source_id>`。身份键还含规范化名称、类型及 document/chunk/local ID scope；同名不同义保持独立。别名属于实体自身作用域，不触发全局合并。
- 跨源实体默认保留不同 ID。`propose_text_alignment` 只有在不同 namespace、类型一致且存在明确 alias quote（含别名表达）或人工映射 ID 时才返回 accepted 决策；它只返回可审计映射，不直接改写实体 ID。
- 关系 confidence 存在 relation `qualifiers["confidence"]`，因为冻结的 `Relation` 没有 confidence 字段；Provenance method 不由 confidence 决定。LLM 估计值不宣称校准概率。
- 抽取器不生成 `RULE_INFERRED` 关系。冻结 Provenance DTO 已要求此方法同时具有非空 premises 与 rule_id。

Entity、Mention、Evidence、Relation 与 Provenance 使用冻结 ID helper 派生；关系 ID 包含 endpoints、predicate、polarity、canonical qualifiers、provenance 和排序后的 evidence IDs。相同输入与输出因此幂等，正反关系仍保留为不同关系。

## 限制

Extractor request 未提供 corpus ID，所以调用方必须通过 extractor 构造参数绑定 corpus；未绑定时拒绝。跨 chunk 的文本实体不自动合并，避免同名异义误合并；需要后续显式 alias 证据或人工映射。Python 调用解析限于局部声明/import 和直接类成员，不遍历继承，不解析运行期 monkey-patch、动态属性、外部依赖类型或所有可能调用。

真实 provider 未在实现阶段调用。离线 fake 结果只验证 DTO、证据定位和拒绝行为，不代表模型质量；live-model gate 仍需在单独授权环境确认。
