## 接口与数据流

`knowledge_weaver.graph.GraphRetriever` 实现 B00 `Retriever` 端口。构造时注入 B03 `GraphStore`、`EntityIndex`（按 `CandidateIndex` 使用）和 `KnowledgeStore`。它只依赖 B00 models/ports 和 B03 的 GraphSnapshot、EntityIndex、Evidence；不导入 B04 或 retrieval 实现。

```python
retriever = GraphRetriever(graph_store, entity_index, knowledge_store)
result = await retriever.retrieve(
    RetrievalQuery(
        text="Pipeline evidence",
        context=context,
        top_k=10,
        entity_ids=[pipeline_entity_id],  # 可省略，届时用 EntityIndex 生成 seed
    )
)
```

每条 `Path` 的 `PathStep` 保存关系 ID、实际遍历起终点、`traversed_reverse` 和该步的 evidence IDs。`RetrievalHit` 按 evidence 所属 chunk 聚合，返回 chunk/evidence/path IDs 与 graph 分数。下游通过 `KnowledgeStore.get_evidence`、`get_chunks` 读取原文；本实现返回前也会对照持久化 Evidence、Chunk 文本和 source-backed span 校验引用。

## 检索规则

- 显式 `RetrievalQuery.entity_ids` 和 `GraphOptions.seed_entity_ids` 合并去重。没有显式 seed 时，EntityIndex 只提供 chunk 候选；候选 chunk 通过 GraphSnapshot 中的 Mention 映射为实体。索引无候选时返回明确空结果，不读取 GraphSnapshot。
- NetworkX `MultiDiGraph` 按 relation ID 保存有向边，平行关系分别保留；边属性保留 predicate、polarity、qualifiers、provenance、source 和 evidence。
- 默认最多 2 跳、200 次边检查；GraphOptions schema 将硬上限限制为 3 跳、500 次边检查。遍历使用 BFS，单条路径不重复实体。超过边预算且仍有待检查边时 `partial=true`。
- `direction=both` 可反向遍历；路径 step 的 from/to 表示遍历方向，relation ID 指向原始关系，反向时置 `traversed_reverse=true`。
- 默认排除 RULE_INFERRED 关系以及只有推断 evidence 的边。source filter 原样传给 EntityIndex 和 GraphStore；检索器只扩展 GraphStore 按同一 generation/filter 返回的快照。跨源边必须至少有一条非推断原始 Evidence，否则拒绝该边。
- 同 subject、predicate、object 和 canonical qualifiers 的显式正反关系分别保留，并在结果 warnings 中报告冲突组数。路径只表示可核查的关系链，不表示因果证明。
- 每个 chunk hit 的 score 是其支持路径 `1 / (1 + hops)` 的最大值。`top_k` 限制完整路径所需的 chunk 数；只有每一步证据 chunk 都能放入结果时才返回该路径。
- 每个实例使用容量为 8 的 LRU 快照缓存；key 含 corpus、generation、规范化 source filter 和 include_inferred。Generation 或 filter 改变不会复用旧快照。

## 错误与边界

- 过期 deadline 返回 `DEADLINE_EXCEEDED`；显式 seed 不在当前 generation/filter 返回 `MISSING_REFERENCE`。
- 引用 Evidence 或 Chunk 缺失返回 `MISSING_REFERENCE`；快照与持久化 Evidence 不一致、quote 不匹配 chunk span 返回 `SCHEMA_INVALID`。
- Snapshot 中端点、provenance 或 evidence 不闭合的关系会被拒绝并计入 warning；不补造缺失边或证据。
- 当前图快照仍由 B03 `GraphStore.snapshot(context)` 提供；B05 限制的是候选 seed、路径跳数和遍历边预算。返回的 evidence IDs 是原文核查入口，B05 不把路径解释成答案或因果结论。
