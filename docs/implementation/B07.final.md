## Decisions

- B07-FINAL-D01 — The scheduler always emits all 111 frozen configurations. Each configuration records both frozen latency cache states (cold, warm) while the configuration count remains 111. The frozen minimum of 40 test cases therefore means 4,440 quality cases and at least 8,880 query executions when both latency states are measured. Larger frozen test splits increase both counts.
- B07-FINAL-D02 — An original Gold span maps only when source path, raw SHA-256, compatible locator, exact quote, one source-backed leaf span, and generation Evidence all close. Overlapping chunks that point to the same original document interval share one evidence-group ID. Repeated quote matches at different source intervals, absent Evidence, or unresolved Gold paths block the complete mapping; no case is dropped.
- B07-FINAL-D03 — The exploration record stores a 12-value B06 feature vector, human-reviewed Gold coverage before/after, source coverage, conflict resolution, observed usage, and identical starting-state hashes for each action branch. It enforces train-only fitting, at most six states per case, and at most eight branches per state. Families with fewer than 24 train rows use the published prior and are disclosed as such.
- B07-FINAL-D04 — Ridge lambda is selected by mean squared Gold-reward error on dev action rows. The complete 3×3 lambda_cost/threshold grid is paired over the same dev cases and seeds 17/29/43; selection maximizes mean (Evidence Recall + normalized Answer Correctness) / 2, then minimizes tokens and latency. The test split is not accepted by fitting or dev-selection contracts.
- B07-FINAL-D05 — Synthetic fixtures can exercise fitting and B06 schema compatibility in memory, but their results are marked synthetic_fixture and cannot be persisted as formal policy weights or counted as benchmark quality. Formal weights require a validated FROZEN dataset and complete dev selection. The B06 loader/model remains unchanged.
- B07-FINAL-D06 — Provider retries are limited to three total attempts and require an explicit transient/retryable classification. Configuration and authentication failures are retained and not retried. Every attempt's usage and failure code is retained.
- B07-FINAL-D07 — Paired bootstrap resamples source-family clusters. A multi-source case joins the families it cites into one bootstrap cluster to avoid duplicating or splitting the same paired case. Fewer than five resulting clusters are marked exploratory.
- B07-FINAL-D08 — Runtime output contains safe case IDs, metrics, usage, provider/model revisions, failure records, and hashes, not prompts or API secrets. Unknown currency cost remains null. A recompute command rebuilds the Markdown report from the saved matrix manifest and per-query JSONL.
- B07-FINAL-D09 — Each suite derives a deterministic query order by shuffling the frozen test-case sequence with its fixed suite seed. The order is preserved by JSONL record order, and the same seed uses the same order across systems and cold/warm cache states.
- B07-FINAL-D10 — An answerable formal query is quality-eligible only with human Answer Correctness and citation precision review; an unanswerable query requires refusal and false-citation measurements. A suite with missing required quality review is recorded incomplete even if provider execution succeeded.
- B07-FINAL-D11 — Reports distinguish quality-case count from query executions across the cold and warm cache measurements.
- B07-FINAL-D12 — Currency cost participates in Pareto dominance when both compared systems have known cost; unknown currency never creates an invented comparison.
- B07-FINAL-D13 — A formal matrix binds an explicit actual generation ID and SHA-256. Missing or malformed identity blocks scheduling; GoldMappingReport must be ready and match both values before execution. The binding is copied into matrix and per-query artifacts and checked again during report recomputation.
- B07-FINAL-D14 — The six-state limit is per case across all trajectories. State identity remains the unique `(trajectory_id, state_index)` pair, preserving branch/state deduplication; the attempt002 regression test confirms the base already enforced this aggregate limit.

## Implemented scope

- gold_mapping.py maps Gold spans and paths against one generation and reports exact blockers.
- scheduling.py creates the full 111-suite matrix and retains missing inputs, provider, budget, dependency, and policy gates.
- training.py validates bounded branch logs, fits the frozen 12-feature ridge model with the B06 weight contract, tunes only on dev, and refuses to write fixture weights.
- runner.py executes suites serially, records cold/warm measurements, enforces frozen per-query budgets, preserves failed attempts, and writes ignored run artifacts.
- query_metrics.py, statistics.py, and reporting.py compute Gold evidence-group and strict chunk Recall, retrieval/evidence/citation/path metrics, paired source-family intervals, cost/latency summaries, and quality-cost Pareto results.
- redaction.py, train_policy.py, and recompute.py provide secret-safe serialization and reproducible fit/report entrypoints.
