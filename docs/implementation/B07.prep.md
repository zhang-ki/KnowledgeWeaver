## Frozen decisions

- `B07-PREP-D01`: fixed replicate seeds are `17`, `29`, and `43`. The plan requires three fixed seeds but does not prescribe values.
- `B07-PREP-D02`: assign whole source families to train/dev/test. The target is 30/20/50 cases; adjust those counts only when indivisible source families require it. Keep at least 15 used families overall, five families per split, 40 test cases, and six test cases per category.
- `B07-PREP-D03`: allow redistributable or local-evaluation-only source material only with a recorded license, rights evidence, verifier, and timestamp.
- `B07-PREP-D04`: do not track original source material unless its license permits redistribution. The repository ignore rules already exclude `data/` and `artifacts/`; the loader accepts local files under the repository root and verifies their raw SHA-256.

## Implementation

- The B00 `BenchmarkCase`, `RunSpec`, and `ExperimentManifest` remain the public base contracts. B07 adds `PreparedBenchmarkCase`, source/license records, timestamped human review checks, exact quote hashes, per-source-record hashes, and original-evidence path records without changing B00.
- The loader confines manifest, case, and source paths to the supplied repository root. It verifies the JSONL hash and case count, each original source hash, every human-review digest, licensed source references, category/language/unanswerable balance, source-family split isolation, and minimum test coverage.
- Deterministic metric helpers cover fixed-denominator Precision@K, Recall@K, MRR, graded nDCG, evidence recall, separate citation support/validity, unanswerable refusal/false-citation rates, and complete directional path coverage. Duplicate claim groups count once; retrieval metrics require answerable Gold groups.
- `benchmarks/configs/b07_protocol_v1.json` freezes nine systems, three budgets, ten ablations, three seeds, the 111-suite formula, fairness controls, and metric definitions. Seven JSON Schemas cover the frozen B00 case/run/manifest contracts and the B07 prepared case, dataset manifest, protocol, and policy weights.
- `RidgePolicyWeights` defines the final-stage artifact shape, the 12 frozen features, train-only fitting, dev-only selection, sample-count fallback disclosure, parameter grids, source hashes, and policy fingerprint. No weights were fitted in prep.
